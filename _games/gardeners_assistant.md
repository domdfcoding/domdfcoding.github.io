Gardener's Assistant is a puzzle game where you plant flowers and place turf to create flower beds from plans. But some of the plans are smudged or upside down, and you need to figure out which flowers need to go where.

[MashUp Game Jam 2024](https://itch.io/jam/mashup-game-jam-2024) Entry. The theme was "A Helping Hand".
